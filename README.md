## ⚙️ Features

* **Terminal-Style Loader** — command-line boot sequence for vibes and accessibility.
* **Matrix Rain Background** — canvas-driven "hacker rain" effect, responsive.
* **Typing Animations** — for Home & About sections (realistic timings and prefers-reduced-motion support).
* **SPA-like Navigation** — hash-based routing + smooth scrolling + active link management.
* **Skills & Blog Animations** — IntersectionObserver for performant reveal effects.
* **Contact Form** — EmailJS integration with mailto fallback to ensure messages always go through.
* **Theme Toggle** — dark/light modes persisted with `localStorage`.
* **Resume Download** — instant client-side trigger for resume.pdf.

## 🛡️ Core Scripts (quick reference)

|           Feature | Class / Component                                | Purpose                                                 |
| ----------------: | :----------------------------------------------- | :------------------------------------------------------ |
|  Loader Animation | `TerminalLoader`                                 | Terminal-like loading sequence before site reveals      |
| Matrix Background | `MatrixRain`                                     | Canvas-driven matrix rain animation                     |
|        Navigation | `NavigationManager`                              | Handles section navigation, hash routing & active links |
| Typing Animations | `HomeTypingController`, `AboutTypingController`  | Home/about typing effects with reduced-motion support   |
|           Contact | `ContactFormHandler`                             | Validates form, sends via EmailJS or mailto fallback    |
|     Skills & Blog | `SkillsAnimationHandler`, `BlogAnimationHandler` | Animations and hover interactions                       |
|             Theme | `ThemeToggle`                                    | Toggle and persist dark/light theme                     |
